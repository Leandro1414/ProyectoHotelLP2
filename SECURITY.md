# Seguridad

Este repositorio no debe contener contraseñas, tokens ni perfiles de publicación.

- Configure `DB_PASSWORD` mediante variables de entorno.
- Guarde el perfil de publicación de Azure únicamente como secreto de GitHub llamado `AZURE_WEBAPP_PUBLISH_PROFILE`.
- Cambie la contraseña de la cuenta demostrativa antes de usar el sistema en un entorno real.
- Si una credencial fue publicada por error, elimínela del historial y cámbiela inmediatamente.
