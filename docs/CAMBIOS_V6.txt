PROYECTO HOTEL - CAMBIOS V6

OBJETIVO
--------
Implementar reportes con el mismo patrón del proyecto bib_v3 usado como referencia:
ReporteController + ReporteService + ReporteServiceImpl + DataSource + JRXML + vistas SQL.

DEPENDENCIA AGREGADA
--------------------
net.sf.jasperreports:jasperreports:6.21.3
Se excluye commons-logging, igual que en el proyecto de referencia.

REPORTES GENERALES
------------------
1. Reporte_Reservas_Hoy.jrxml
   Ruta: /reportes/reservas-hoy
   Fuente: vista_reservas_hoy

2. Reporte_Consumos_Hoy.jrxml
   Ruta: /reportes/consumos-hoy
   Fuente: vista_consumos_hoy

DOCUMENTO PARAMETRIZADO
-----------------------
3. Comprobante_Reserva.jrxml
   Ruta: /reportes/comprobante/{idReserva}
   Parámetro Jasper: idReserva
   Fuente: vista_comprobante_reserva

ARCHIVOS JAVA
-------------
- controller/ReporteController.java
- service/ReporteService.java
- service/impl/ReporteServiceImpl.java

INTERFAZ
--------
- Nuevo enlace Reportes en la barra de navegación.
- Nueva pantalla templates/reporte/index.html.
- Accesos rápidos desde el dashboard.
- Botón PDF en la lista de reservas.
- Botón Comprobante PDF en el detalle de cada reserva.

BASE DE DATOS
-------------
- db_ReservasHotel.sql ya incluye las vistas de Jasper.
- db_Reportes_V6.sql permite actualizar una base V5 sin eliminar datos.

SEGURIDAD
---------
Las rutas /reportes/** requieren autenticación y admiten los roles ADMIN y RECEPCIONISTA.

PRUEBA AUTOMATIZADA
-------------------
ReporteJrxmlTests compila los tres archivos JRXML para detectar errores de plantilla durante mvn test.
