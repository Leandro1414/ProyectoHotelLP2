CÓMO ACTIVAR LOS REPORTES EN HOTEL EXCLUSIVE V6

CASO A: YA TIENES LA BASE LP2Final DE LA V5
1. Abre MySQL Workbench.
2. Ejecuta db_Reportes_V6.sql.
3. No ejecutes db_ReservasHotel.sql, porque elimina y recrea la base.
4. Importa o reemplaza el proyecto reservaHotel.
5. En Spring Tool Suite: Maven > Update Project.
6. Espera a que Maven descargue JasperReports 6.21.3.
7. Ejecuta Project > Clean.
8. Inicia como Spring Boot App.
9. Entra a http://localhost:8091/reportes.

CASO B: INSTALACIÓN DESDE CERO
1. Ejecuta db_ReservasHotel.sql.
2. Importa reservaHotel como Existing Maven Project.
3. Ejecuta Maven > Update Project.
4. Inicia como Spring Boot App.

PRUEBAS RÁPIDAS
- Ver reservas de hoy: http://localhost:8091/reportes/reservas-hoy
- Ver consumos de hoy: http://localhost:8091/reportes/consumos-hoy
- Ver comprobante de reserva 1: http://localhost:8091/reportes/comprobante/1

DESCARGA DIRECTA
Agrega ?modo=descargar al final de cualquiera de las rutas generales.
Ejemplo: http://localhost:8091/reportes/reservas-hoy?modo=descargar

IMPORTANTE
Los reportes diarios utilizan CURDATE() de MySQL. Si no hay registros creados en la fecha actual, el PDF mostrará el mensaje de que no existen datos para hoy.
